# Heart-Rate-Monitoring-Using-NodeMCU-ESP8266-and-KiwisIoT
Heart Rate Monitoring using NodeMCU ESP8266 and a pulse sensor with real-time BPM measurement and data visualization through the KiwisIoT platform.
Heart Rate Monitoring Using NodeMCU ESP8266 and KiwisIoT
About the Project
The Heart Rate Monitoring is an IoT-based project designed to measure and monitor a person's heart rate in real time.

Using a NodeMCU ESP8266 microcontroller and a pulse sensor, the system detects heartbeat signals and calculates the heart rate in beats per minute (BPM). The collected heart rate data is transmitted to the KiwisIoT platform through Wi-Fi, allowing users to view and monitor readings remotely through an online dashboard.

By integrating KiwisIoT, this project demonstrates a simple approach to IoT-based health monitoring, real-time data visualization, and remote sensor monitoring.
